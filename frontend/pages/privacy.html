Information this application handles

The database stores bus, route, stop, and timestamped location data submitted by drivers while trips are active. The demo sign-in stores the display name and selected role in the current browser tab. It does not create a user account.

Location information

The driver page requests browser geolocation while a trip is active and sends position updates to the server. The student page can request browser geolocation to calculate distance from the bus locally; it does not send that student location to the bus API. The application has no configurable location-retention or deletion schedule. Operators must define these before real use.

Service providers

Transit pages load map assets from Leaflet's CDN, map tiles from OpenStreetMap, and fonts from Google Fonts. These providers may receive your IP address and browser request metadata when the resources load. The operator must document its hosting, database, and logging providers before public launch.

Storage and security

The project login is a demo role selector and does not authenticate or authorize users. Do not enter sensitive personal information. The operator must restrict access to the server and database, define retention, and add real authentication before public use.

Your choices

Before using this service with real riders, the operator must publish a contact address and explain how to request access, correction, or deletion of location data.
